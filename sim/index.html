Backup / restore your Voyetra (SysEx over MIDI)

Saves the 100 programs and 100 steps to a .syx file, and writes them back. Do this with the stock ROM before putting NeoV8 in (docs/burning.md). Connect both MIDI cables (the Voyetra's OUT to your interface's IN, and its IN to the interface's OUT), and turn SysEx on: stock Rev4 MX (MIDI MISC, Alternate page = A440+STEP ENABLE), NeoV8 menu 16 rS. For a restore, also turn memory protect off.

A full backup takes about 15 s, a restore about 45 s (it reads everything back to check it).
Quick reference

Play (Normal page)

  • CALL L / CALL R + 2 digits: recall a program. FWD/REV: browse ±1.
  • CALL STEP (ENABLE) + 2 digits: recall a performance step.
  • EDIT: edit the side you last called. EDIT again: back.
  • STORE → digits/FWD/REV pick destination → STORE commits, EDIT cancels.
  • A440+STORE: compare when edited, otherwise undo the last store.
  • A440+CALL: init (null) program. A440+EDIT: SYSTEM menu.
  • Hold SPLIT and press a key: split point.

Edit

  • Pages 1, 2, A, B, C, D: FWD/REV, or EDIT + 1..6 (right-click EDIT to latch, then click a digit).
  • Touching any control shows its name + value. Decimal point on the program number = edited.
  • Pickup: ‾ = turn up, _ = turn down until the knob catches the stored value.
  • A440+FWD/REV: ±1 on the last touched parameter.
  • CALL L / R: switch the edited side.

Computer keyboard

  • Notes: Z S X D C V G B H N J M , (←/→ octave)
  • Keypad 0-9, FWD ], REV [
  • EDIT Esc, STORE Enter, A440/SHIFT Shift
  • CALL L Q, CALL R W, CALL STEP E, STORE STEP R
  • SPLIT T, WHOLE Y, LAYER U
